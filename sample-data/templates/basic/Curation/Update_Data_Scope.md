## Update Data Scope
> Update the Data Scope classification (0210) already applied to an element: any of its time periods, bounds, scope elements and additional properties.

### Target Element
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: Qualified name of the existing element being classified or linked.


### Data Collection Start Time
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Start time for the data collection period.


### Data Collection End Time
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: End time for the data collection period.


### Data Validity Start Time
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Start of the period for which the data is valid, ISO 8601 (dataValidityStartTime).


### Data Validity End Time
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: End of the period for which the data is valid, ISO 8601 (dataValidityEndTime).


### Data Coverage Start Time
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Start of the period the data covers, ISO 8601 (dataCoverageStartTime).


### Data Coverage End Time
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: End of the period the data covers, ISO 8601 (dataCoverageEndTime).


### Min Longitude
>	**Input Required**: False

>	**Attribute Type**: Simple Float

>	**Description**: Minimum longitude of the geographic scope.


### Max Longitude
>	**Input Required**: False

>	**Attribute Type**: Simple Float

>	**Description**: Maximum longitude of the geographic scope.


### Min Latitude
>	**Input Required**: False

>	**Attribute Type**: Simple Float

>	**Description**: Minimum latitude of the geographic scope.


### Max Latitude
>	**Input Required**: False

>	**Attribute Type**: Simple Float

>	**Description**: Maximum latitude of the geographic scope.


### Min Height
>	**Input Required**: False

>	**Attribute Type**: Simple Float

>	**Description**: Minimum height of the vertical scope.


### Max Height
>	**Input Required**: False

>	**Attribute Type**: Simple Float

>	**Description**: Maximum height of the vertical scope.


### Scope Elements
>	**Input Required**: False

>	**Attribute Type**: Dictionary

>	**Description**: Map of element identifiers defining the scope of the data lens or data scope.

>	| Parameter Name | Parameter Value |
>	|---|---|
>	| example_key | example_value |


### Journal Entry
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: A text entry into a journal.
