## Unlink Peer Duplicate
> Remove a PeerDuplicateLink relationship between two elements (duplicate management).

### Target Element
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: Qualified name of the existing element being classified or linked.


### Peer Duplicate
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: Qualified name of the other element known to represent the same real-world thing (PeerDuplicateLink).


### Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: A label used to identify or categorise a relationship link.

>	**Alternative Labels**: Wire Label


### Duplicate Notes
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Notes explaining why elements were classified or linked as duplicates.


### Journal Entry
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: A text entry into a journal.


### Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: A description.
