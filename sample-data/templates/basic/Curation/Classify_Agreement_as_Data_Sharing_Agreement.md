## Classify Agreement as Data Sharing Agreement
> Classify an existing Agreement as a Data Sharing Agreement (retrofit -- Create Data Sharing Agreement already sets this classification at creation time; this is for an Agreement that already exists).

### Target Element
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: Qualified name of the existing element being classified or linked.


### Journal Entry
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: A text entry into a journal.
