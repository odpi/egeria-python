## Classify Known Duplicate
> Classify an element to indicate it has one or more known duplicates in the metadata ecosystem (duplicate management).

### Target Element
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: Qualified name of the existing element being classified or linked.


### Duplicate Notes
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Notes explaining why elements were classified or linked as duplicates.


### Journal Entry
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: A text entry into a journal.
