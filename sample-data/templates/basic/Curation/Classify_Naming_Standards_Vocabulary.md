## Classify Naming Standards Vocabulary
> Classify an existing Glossary as a naming standards vocabulary -- a glossary that describes the terms used in naming standards (0438).

### Target Element
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: Qualified name of the existing element being classified or linked.


### Journal Entry
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: A text entry into a journal.
