## Detach Relational DB Schema
> Remove a RelationalDBSchema relationship between two schema elements.

### Database Schema Type List GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the database schema type list.


### Relational DB Schema Type GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the relational database schema type.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
