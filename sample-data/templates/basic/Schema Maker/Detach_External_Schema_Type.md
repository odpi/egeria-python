## Detach External Schema Type
> Remove a LinkedExternalSchemaType relationship between two schema elements.

### Schema Element GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the schema element (schema type or attribute) at the non-schema-type end of this relationship.


### External Schema Type GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the externally-defined schema type being linked/reused.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
