## Detach Foreign Key
> Remove a ForeignKey relationship between two schema elements.

### Primary Key Column GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the schema attribute acting as the primary key column.


### Foreign Key Column GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the schema attribute acting as the foreign key column.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
