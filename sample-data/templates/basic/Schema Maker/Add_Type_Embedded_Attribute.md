## Add Type Embedded Attribute
> Add the TypeEmbeddedAttribute classification to a schema attribute.

### Schema Attribute GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the schema attribute.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.


### Embedded Data Type
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Data type embedded in the parent attribute's type (TypeEmbeddedAttribute classification).


### Embedded Default Value
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Default value embedded in the parent attribute's type.


### Embedded Fixed Value
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Fixed value embedded in the parent attribute's type.
