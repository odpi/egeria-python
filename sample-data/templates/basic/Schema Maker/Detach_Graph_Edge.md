## Detach Graph Edge
> Remove a GraphEdgeLink relationship between two schema elements.

### Graph Edge GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the graph edge schema attribute.


### Graph Vertex GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the graph vertex schema attribute.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
