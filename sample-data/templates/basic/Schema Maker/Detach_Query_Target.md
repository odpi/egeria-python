## Detach Query Target
> Remove a DerivedSchemaTypeQueryTarget relationship between two schema elements.

### Schema Element GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the schema element (schema type or attribute) at the non-schema-type end of this relationship.


### Query Target Schema Element GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the schema element used as the query target for a derived schema type.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
