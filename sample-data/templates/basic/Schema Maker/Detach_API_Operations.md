## Detach API Operations
> Remove a APIOperations relationship between two schema elements.

### API Schema Type GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the API schema type.


### API Operation GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the API operation schema attribute.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
