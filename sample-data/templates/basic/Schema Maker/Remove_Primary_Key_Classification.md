## Remove Primary Key Classification
> Remove the PrimaryKey classification from a schema attribute.

### Relational Column GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the relational column schema attribute.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
