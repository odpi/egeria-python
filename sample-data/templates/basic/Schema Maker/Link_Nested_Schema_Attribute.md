## Link Nested Schema Attribute
> Establish a NestedSchemaAttribute relationship between two schema elements.

### Schema Attribute GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the schema attribute.


### Nested Schema Attribute GUID
>	**Input Required**: True

>	**Attribute Type**: Reference Name

>	**Description**: GUID of the nested (child) schema attribute.


### Link Label
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional label/name for this relationship.


### Link Description
>	**Input Required**: False

>	**Attribute Type**: Simple

>	**Description**: Optional description of this relationship.
