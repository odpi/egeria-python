# sample-data/templates

Markdown command templates, one file per Dr.Egeria command, generated by
`gen_md_cmd_templates` from the compact command JSON specs
(`md_processing/data/compact_commands/`) — these are for users authoring
Dr.Egeria markdown, not test fixtures.

```
gen_md_cmd_templates            # regenerates basic/ (Basic attributes only)
gen_md_cmd_templates --advanced # regenerates advanced/ (all attributes)
```

- `basic/` — templates showing only Basic-level attributes (the common case).
- `advanced/` — templates showing every attribute, including Advanced/Domain-level ones.

Both are organized into the same family subfolders (`Action Author`,
`Actor Manager`, `Collections`, `Curation`, `Data Designer`, `Digital
Product Manager`, `External Reference`, `Feedback`, `Glossary`,
`Governance Officer`, `Lineage Linker`, `Projects`, `Reference Data`,
`Solution Architect`, `Views & Reports`) — one matching the command's own
compact-spec `family`.

These files are generated — don't hand-edit them; re-run
`gen_md_cmd_templates` after changing a compact command spec instead (see
the root `CLAUDE.md`'s "Key CLI tools" section).
