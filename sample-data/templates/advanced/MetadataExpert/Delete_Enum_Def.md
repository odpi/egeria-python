## Delete Enum Def
> Delete an enum definition. WARNING: currently fails on Egeria with a 500 'unknown TypeDef' (ISSUE-125).

### Enum Def Name
>	**Input Required**: True

>	**Attribute Type**: Simple

>	**Description**: Name of the enum definition.


### Enum Def GUID
>	**Input Required**: False

>	**Attribute Type**: GUID

>	**Description**: GUID of the enum definition. If omitted, it is looked up from the Enum Def Name.
