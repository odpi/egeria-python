## Delete Type Def
> Delete a type definition that was added through the API. Fails while instances of the type exist or another type refers to it.

### Type Def Name
>	**Input Required**: True

>	**Attribute Type**: Simple

>	**Description**: Name of the open metadata type definition (entity, relationship or classification).


### Type Def GUID
>	**Input Required**: False

>	**Attribute Type**: GUID

>	**Description**: GUID of the type definition. If omitted, it is looked up from the Type Def Name.
