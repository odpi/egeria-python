# pyegeria 6.2.28

## Changed

- **A failed viewer count is `None`, not `0`.** `count_elements`, `count_elements_by_property` and
  the composites built on them (`counts_by_type`, `people_counts`, `usage_context_counts`) returned
  `0` in the viewer population when the query itself failed, unless `strict=True`. That read as
  "none of them". It is now `None` with an `unmeasured` note, strict or not, as a repository count
  already was. `strict` is still accepted and changes nothing.

See [Counts: not measured, and whose population](../output-formats-and-report-specs.md#counts-not-measured-and-whose-population).
